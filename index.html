Cài hoặc cập nhật IOE AI Assistant bằng Tampermonkey. Mã nguồn luôn lấy trực tiếp từ repository GitHub của dự án.

Cài / cập nhật script Tải Tampermonkey

Nút “Copy toàn bộ mã nguồn” tải nội dung file RAW rồi sao chép vào clipboard. Nếu trình duyệt chặn clipboard, trang sẽ hiện ô để mày tự sao chép.

Quick setup

Bắt đầu trong 3 bước

01

Cài tiện ích

Mở trang Tampermonkey và cài tiện ích phù hợp với trình duyệt.

02

Mở trình cài script

Nhấn “Cài / cập nhật script”, sau đó xác nhận trong Tampermonkey.

03

Quay lại trang học tập

Tải lại trang IOE, VioEdu hoặc Violympic nằm trong danh sách hỗ trợ.

Lưu ý

Trang web không thể xác minh chắc chắn Tampermonkey đã cài hay chưa. Nếu nút cài chỉ mở mã nguồn, hãy kiểm tra cài đặt của tiện ích rồi thử lại.
